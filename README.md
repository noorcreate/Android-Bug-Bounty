# Android-Bug-Bounty
My personal journey of "pentesting" from a mobile device. No root, no desktop. Making use of everything that's possible in the cyber security world.

# Tools/Apps I Use 
Termux - The GOAT, OG. Practically any lightweight CLI tool could be run here.

mitmproxy - especially mitmdump, complete package for HTTPS traffic testing.

Reqable - Pretty basic, not used much.

Mises - Browser which allows extensions and has DevTools built in, don't expect much from the Devtools however it is pretty bad.

Eruda - Better browser with nice Devtools functionality, but sometimes doesn't work.

PCAPdroid - Barely used.

Claude and Deepseek - Claude's good for writing your custom code, but Deepseek is also very unfiltered for testing on targets. Both are good.

Proxy Toggle - It does what it says. https://github.com/theappbusiness/android-proxy-toggle
